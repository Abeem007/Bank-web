# 🏦 EasyBank Website

A modern, responsive banking website built using **React** and **Vite**, showcasing a clean UI with animated transitions, navigation, and informative pages for users.

🔧 **Note:** While the homepage design was based on the Frontend Mentor challenge, **the About, Blog, Careers, and Contact pages were personally added and implemented by me** to expand the project and enhance its real-world application.

## 🚀 Features

- 🌐 **Home Page** – Landing page introducing the bank’s services and mission.
- 📖 **About Page** – Details the bank’s goals and financial literacy initiatives.
- 📰 **Blog Page** – Space for financial articles, tips, and announcements.
- 💼 **Careers Page** – Space for career information.
- 📞 **Contact Page** – Contains office address and helpdesk details with tabbed navigation.

✅ Fully **responsive**  
✅ Mobile-friendly navigation  
✅ Smooth **Framer Motion** animations  
✅ Clean **Tailwind CSS** layout  

## 🛠 Tech Stack

- ⚛️ **React** (with [Vite](https://vitejs.dev/) for fast development)
- 🎨 **Tailwind CSS** – For modern styling and responsive design
- 🎞 **Framer Motion** – Smooth animations and transitions
- 🧭 **React Router** – For client-side routing
